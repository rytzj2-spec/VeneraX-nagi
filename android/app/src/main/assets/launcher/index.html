登录小站

和电脑版 Nagisaland 用同一个账号。
流程：在「小站」获取链接并用网盘下载 → 这里点「解压」→「一键解压到游戏库」：自动改回伪装后缀、认分卷、依次试解压密码、压缩包套压缩包也一路解到底、删广告、去掉多余的文件夹层、用小站的名字和封面入库。用别的 App 解压的，回来点「找解压出来的游戏」也能入库。
已安装的模拟器会被自动识别；游戏库里点游戏时会直接调起对应的 App。
