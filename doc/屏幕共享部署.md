# 屏幕共享「经服务器」部署说明

手机 App 里「一起看 → 共享我的屏幕 → 经服务器共享」要用到小站那台服务器（谷歌云 e2-micro，下面用 `<你的域名>` 代指小站的域名）。
服务器只**牵线**（开房间、转发连接信息、发 TURN 临时凭据），视频不经过它：

```
手机（房主） ──WebRTC 直连──▶ 浏览器（观看者）        能直连时：不花任何服务器流量
      └──────▶ TURN 中转 ──────▶                      连不上时：Cloudflare 或自建 coturn 转发
      └─ wss://<你的域名>/share/ws ─┐
浏览器 ─ https://<你的域名>/share/ ─┴─▶ Nginx ─▶ nagi-share（127.0.0.1:8090，Python，约 15 MB 内存）
```

代码在 `server/nagi_share/`：

| 文件 | 作用 |
| --- | --- |
| `nagi_share.py` | 牵线服务（websockets 12，单进程，systemd 管） |
| `web/index.html` | 观看页面（浏览器打开，能发弹幕、看是「直连」还是「经中转」） |
| `config.example.json` | 配置示例；服务器上的真配置在 `/opt/nagi-share/config.json`（640 权限，不进 Git） |
| `deploy_nagi_share.py` | 部署脚本（paramiko，和小站的其它部署脚本一样在 Windows 上跑） |

## 一、选 TURN（直连不上时的中转）

| | Cloudflare Realtime TURN（推荐） | 自建 coturn |
| --- | --- | --- |
| 费用 | 每月 1000 GB 免费，超出 $0.05/GB | 走谷歌云出站流量（发往国内不在免费额度里，按量计费） |
| 服务器负担 | 无（转发在 Cloudflare） | e2-micro 上跑，已限速：每会话约 3 Mbps、总共约 12 Mbps |
| 要准备 | Cloudflare 账号 → Realtime → TURN Server 建一个 Key | 子域名 `turn.<你的域名>`（**灰色云**）+ 谷歌云防火墙开端口 |
| 国内效果 | 能用，不一定稳 | 取决于谷歌云到国内的线路 |

两种都写好了，`--turn` 参数随时切换；`--turn both` 两个都开，手机「一起看」页面的「中转」里可以选「自动 / Cloudflare / 自建」
（自动 = 两个都给，浏览器 / 手机自己挑能通的、更快的）。先用 Cloudflare，看观看页「统计」里的往返延迟和丢包再决定要不要加自建。

## 二、Cloudflare TURN（推荐）

1. Cloudflare 控制台 → **Realtime** → **TURN Server** → Create，记下 **Turn Token ID（Key ID）** 和 **API Token**（只显示一次）。
2. 在 `server/nagi_share/` 旁边建 `nagi_share_secrets.json`（已在 `.gitignore`，不会进 Git）：

   ```json
   {"cloudflare_key_id": "这里填 Key ID", "cloudflare_api_token": "这里填 API Token"}
   ```

   不建这个文件也行：部署时会问，输入 Token 时不显示。
3. 部署：

   ```bat
   cd server\nagi_share
   python deploy_nagi_share.py --turn cloudflare
   ```

## 三、自建 coturn（备用）

1. Cloudflare DNS 加一条 **A 记录** `turn` → 服务器当前外部 IP，**代理状态必须是灰色云（仅 DNS）**（Cloudflare 代理只转发 HTTP，TURN 走不过去）。
   服务器 IP 变了要改这条记录（coturn 自己会在每次启动时从谷歌云元数据读新 IP，不用改服务器上的配置）。
2. 谷歌云防火墙放行（控制台 → VPC 网络 → 防火墙，或在本地电脑用 gcloud）：

   ```bash
   gcloud compute firewall-rules create nagi-turn --direction=INGRESS --action=ALLOW --rules=udp:3478,tcp:3478,udp:49160-49200 --source-ranges=0.0.0.0/0
   ```

3. 部署：

   ```bat
   python deploy_nagi_share.py --turn coturn
   ```

   coturn 的配置：只接受牵线服务发的临时凭据（`use-auth-secret`，12 小时有效）；同时最多 12 个转发、每个用户 4 个；
   不许转发到内网地址（防止被当跳板）；密钥自动生成，只在服务器的 `/opt/nagi-share/config.json` 和 `/etc/turnserver.conf` 里。

## 部署前：服务器信息放在本地文件里

这个仓库是公开的，服务器 IP、私钥路径、域名都不写进代码。在 `server/nagi_share/` 里建 `deploy_local.json`（已在 `.gitignore`）：

```json
{"host": "服务器外部 IP", "key": "C:\\key\\私钥文件", "domain": "你的域名"}
```

IP 变了改这个文件（或设环境变量 `GALSITE_HOST`）。

## 四、部署脚本做了什么

1. 备份：Nginx 的 `galsite` 站点配置、旧的 `config.json` / `nagi_share.py` / `turnserver.conf` → `/opt/nagi-share/_bak_<时间>/`（留最近 5 份）
2. 上传程序和观看页面到 `/opt/nagi-share/`，建 venv、装 `websockets`
3. 生成 / 更新 `config.json`（密钥不打印）
4. （`--turn coturn` 时）装 coturn、写配置、开机自启
5. 注册 `nagi-share` 服务（独立的 `nagishare` 用户、内存上限 80 MB、开机自启）
6. 在 `/etc/nginx/sites-available/galsite` 的 `location / {` 前面加一段 `/share/`（`# >>> nagi-share` 标记之间，重复跑会替换），
   `nginx -t` 不过就自动还原备份
7. 验证：`/share/` 页面 200、小站首页 200、经 Nginx 实际开一个测试房间，看 ICE 服务器里有没有 TURN

**不动小站本身**（`/opt/galsite`、`galsite.service`、Gunicorn）。

其它命令：

```bat
python deploy_nagi_share.py --status      看服务状态和最近日志
python deploy_nagi_share.py --rollback    还原上一次部署前的 Nginx / 配置
```

服务器 IP 变了：改 `deploy_local.json` 的 `host`，或者设环境变量 `GALSITE_HOST`。

## 五、手机上用

「更多 → 一起看 → 共享我的屏幕」：

- 服务器地址第一次要填 `https://<你的域名>/share/`（之后记住；「一键配置」导出时会带上，朋友导入后不用填），可以填房间密码（会带在分享链接里）、选清晰度（清晰 3 Mbps / 标准 2 Mbps / 省流 1 Mbps）
- 点「经服务器共享」→ 允许录音（录的是手机正在播放的声音）→ 允许录屏 → 弹出邀请链接，复制或分享
- 对方用浏览器打开链接就能看；右上角显示「直连」或「经中转」；底部能发弹幕（手机上以提示的形式显示）
- 停止：通知栏「停止共享」，或再进「共享我的屏幕」点停止

## 稳定性（v0.23.0 起）

- 牵线（WebSocket）断了不会结束共享：手机和观看页都自动重连，回到原来的房间；房主 / 观看者掉线后服务器保留 60 秒。
  已经在播的画面不经过牵线服务器，断牵线时画面照常。手机和观看页每 25 秒发一次心跳（Cloudflare 代理的 WebSocket 空闲约 100 秒会断）。
- 画面连接断开 5 秒或失败：手机自动重新协商（ICE restart），最多 3 次。
- 只有这几种情况会结束共享，结束原因会显示在观看页和手机上：你点了停止；系统收回了录屏权限；启动失败；
  掉线超过 60 秒（房间换新的，要重新发链接）。
- 手机端事件日志：`内部存储/Nagisaland/debug/share.txt`（开始、断开、重连、ICE 状态、每 30 秒一次统计、结束原因）。

## 六、排查

| 现象 | 看哪里 |
| --- | --- |
| 手机提示「连不上服务器」 | 浏览器打开 `https://<你的域名>/share/` 能不能出页面；`python deploy_nagi_share.py --status` |
| 能进房间但一直「等画面」/「连不上房主」 | 直连不通又没有可用的 TURN：看 `--status` 日志里有没有「TURN 凭据获取失败」；Cloudflare Token 对不对；coturn 防火墙 / 灰色云 |
| 一直「经中转」、画面卡 | 手机流量网络常见，直连打不通。打开观看页右上角「统计」：丢包高 / 往返延迟高 = 线路问题（换 Wi-Fi、清晰度调「省流」，或试 `--turn both` 的自建中转）；码率上不去但不丢包 = 带宽估计慢，等十几秒或调「清晰」 |
| 共享自己结束了 | 看手机 `内部存储/Nagisaland/debug/share.txt` 最后几行的「结束：…」 |
| 没有声音 | 观看页点「打开声音」；手机要 Android 10+ 并允许录音；有的 App 不允许被录声音 |
| 画面是黑的 | 视频 App 有版权保护（系统限制），换别的 App 或局域网模式也一样 |

## 外部 coturn（国内中转机，2026-11-04）

coturn 可以装在另一台服务器上（例如国内的轻量服务器，直接用公网 IP + 3478，不用域名、不用备案）。牵线服务器的 `/opt/nagi-share/config.json` 里：

```json
"turn": "both",
"coturn": {"host": "<中转机公网 IP>", "port": 3478, "secret": "<中转机 turnserver.conf 的 static-auth-secret>", "ttl": 43200, "external": true}
```

- `external: true`：部署脚本不会改 host，也不会在牵线服务器上装 coturn。
- `both` 时自建 coturn 排在 Cloudflare 前面；连不上会自动用 Cloudflare。
- 中转机上：`apt install coturn`，配置 `use-auth-secret`、`static-auth-secret`、`external-ip=<公网>/<内网>`、`min-port/max-port`，防火墙放行 UDP+TCP 3478 和中转端口段。IP、密钥不进 Git。
