# 统一侧栏与本地构建

分支继续使用 `feature/android-companion`，稳定的 `unify-app` 不变。

## 本轮界面

参考用户提供的抽屉式导航结构，保留 Nagisaland 深色粉紫配色，不增加充值、积分或虚构账号。

- 漫画、番剧标题左侧新增菜单按钮；游戏库／小站／解压／模拟器的网页标题栏也有入口。
- 陪伴和原生「更多」页面的标题左侧提供入口；所有原生分区底栏「更多」统一打开侧栏。
- 侧栏列出已开启分区，沿用现有顺序；当前分区高亮。不会绕过 `.nagi` 的分区限制。
- 常用功能包含一起看、一键配置、当前分区设置、编辑底栏、流畅度与手势。
- 点击分区关闭侧栏并沿用原有常驻切换方式；点击遮罩、关闭按钮或系统返回关闭侧栏。
- 侧栏从左侧滑入、向左滑出；这里是打开／关闭动画，**没有加入边缘滑动手势**，避免抢占原有返回手势。
- 页面暂停、销毁时关闭侧栏，避免切后台／旋转时窗口残留。
- 顶部标签用于分区内部导航；底栏仍保留常用应用分区，符合参考图的“侧栏 + 主内容 + 底栏”结构。

## 本地拿到分支

GitHub 登录已恢复，但 Git push 和连接器写入均返回 403，开发分支尚未上传。当前请使用 `nagisaland-companion.bundle` 离线获取分支；待确认远程推送成功后再从远程更新。
下载到 F 盘后，在终端执行一行（路径按实际下载位置调整）：

```powershell
git clone -b feature/android-companion F:\NagiDev\tmp\nagisaland-companion.bundle F:\NagiDev\Nagisaland-feature
```

这会创建单独的源码目录，不覆盖原有 `VeneraX-nagi-suite`。本地 `key.properties`、`dart_defines.txt`、`nagi_local.properties` 等配置仍使用你自己的，不在源码包中。
若使用编译监听器，请给此测试目录单独配置路径；不要直接覆盖稳定工作目录。

常规构建继续使用原签名配置：

```powershell
flutter pub get
flutter build apk --release --target-platform android-arm64 --dart-define-from-file=dart_defines.txt
```

没有 `dart_defines.txt` 时去掉对应参数。正式签名和模拟器注入继续使用原来的打包脚本。
本分支尚未改动 `versionCode`；正式出包前再确定测试版本号。同包名同签名的 APK 是覆盖安装，不是并行安装。

新增的 `nagiUnsignedBuild=true` 仅供没有签名文件的环境显式选择未签名构建；默认关闭，不改变你的正常本地签名流程。
不用在本地开启它。未签名产物不能直接安装，也不应拿临时签名覆盖已有 App。
